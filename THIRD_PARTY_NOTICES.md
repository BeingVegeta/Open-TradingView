## Zerodha Kite Connect

Market data is retrieved from Zerodha's Kite Connect API using the official
[`kiteconnect`](https://github.com/zerodha/kiteconnectjs) SDK (MIT) and direct
HTTP calls. Kite Connect's terms forbid redistributing its market data; this
application is for the account holder's personal use on their own machine.
